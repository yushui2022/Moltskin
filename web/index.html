使用帮助

三步开始，以及常见问题的处理方式

1. 准备代理（可选）

在「代理 IP」添加 HTTP 或 SOCKS5 代理并检测，确认出口 IP 与目标地区一致。

2. 创建环境

创建时系统会生成一份随机指纹并永久保存；同一环境每次启动都是同一身份。

3. 打开窗口

点击「打开」启动独立的 Camoufox 实例，登录状态保存在该环境自己的数据目录里。

常见问题

· 环境显示「异常」：上次进程被强制结束，重新打开即可恢复。
· 打开失败并提示并发上限：到「设置 → 最大同时运行」调高上限。
· 指纹自检需要环境处于关闭状态，会在 CreepJS 中截图。
